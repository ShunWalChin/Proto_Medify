# Segurança

Não abra issue pública contendo vulnerabilidade, senha, token, dado pessoal ou
dado clínico. Comunique o mantenedor por canal privado do GitHub e inclua somente:

- componente/versão;
- impacto;
- passos mínimos sem dado real;
- evidência redigida;
- sugestão de contenção.

Credencial exposta deve ser revogada imediatamente; remover do Git não desfaz a
exposição no histórico.

- [segurança clínica e LGPD](05-SECURITY-LGPD-CLINICAL.md);
- [threat model](docs/security/THREAT-MODEL.md);
